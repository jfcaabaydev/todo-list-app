# todo-list-app

A simple todo list app, for people who struggle to keep track on their tasks, add your task, save, complete and delete, built with JavaScript with local storage.

## Installation

1. Clone this repository to your computer:

    ```bash
    git clone https://github.com/jfcaabaydev/todo-list-app
    ```

2. Open the index.html file in a web browser to run the todo-list-app.

## Technologies Used

- HTML
- CSS
- JavaScript
